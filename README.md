# ChemoSim 0.6

Browser-based E. coli chemotaxis exploration tool. Defaults are exploratory, not a universal experimentally calibrated wild-type model. See MOTOR_MODEL.md, UPSTREAM_MODEL.md and PUBLICATION_REVIEW.md for scope and limitations.

## GitHub Pages
Upload all files in this folder to the repository root. In Settings > Pages select Deploy from a branch, main, /(root), then Save. No build or package installation is required.
